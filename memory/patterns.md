# Patterns

Conventions from the project brief, existing project baseline and inspected sources. Code examples below are documentation locators until implementation exists.

### P-1 - Stephen confirms completion
- Rule: Agent reports verified implementation awaiting Stephen's confirmation; it does not invent owner sign-off or mark planned work complete.
- Applies when: Updating task status, reporting completion or publishing a launch report.
- Example: AGENTS.md, Plan and approval.
- Date: 2026-10-22

### P-2 - Preserve homepage branding and accessible rem typography
- Rule: Carry dark backgrounds and blue accents across pages; improve layout and contrast; use rem typography, responsive layouts and WCAG 2.2 AA as the target.
- Applies when: Designing components, migrating styles or reviewing responsive pages.
- Example: OderindeStephen-Headless-Build-Plan-v1.md, section 8.
- Date: 2026-10-22

### P-3 - Export evidence is not live behavior
- Rule: Cite original file/source ID/block locator for export claims. Verify actual CMS, rendered behavior, recipients, redirects, private content and delivery separately.
- Applies when: Mapping Divi content, assessing functionality or writing implementation evidence.
- Example: docs/source-audit.md and reference/normalized/summary.json.
- Date: 2026-10-22
